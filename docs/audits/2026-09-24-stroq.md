# Stroq audit, 2026-09-24

**Snapshot:** `main` at 0.16.0 (`557bc66`). macOS arm64, Node 24.13.1. Every case below was reproduced on the built CLI with synthetic data in temporary directories, then fixed, with a regression test.

This audit is a follow-up to [2026-09-23](2026-09-23-stroq.md), which covered the engine, classifiers, cloak, audit log, installers and release pipeline. It deliberately looked where that one did not: what Stroq **prints**, what it **writes into a repository someone else wrote**, and the code added since.

## Findings

| ID | Severity | Finding | Status |
| --- | --- | --- | --- |
| B-01 | Medium | Attacker-written text reached the terminal and the agent's UI as raw control sequences | Fixed |
| B-02 | Medium | `stroq init` wrote through a repository's symlink into a file outside the project | Fixed |
| B-03 | Low | A config parse error quoted the start of the file, which a symlink can make a credential file | Fixed |
| B-04 | Low | A config symlinked to `/dev/zero` hung `doctor`, `init` and `exposure` until memory ran out | Fixed |
| B-05 | Low | Quadratic backtracking in the `sent` heredoc filter: 42 s on a 400 KB command | Fixed |
| B-06 | Low | `SECURITY.md` pointed researchers at limits "the README documents" after the README was cut to 39 lines | Fixed |

### B-01 · Control sequences from recorded sessions

`stroq replay` printed 7 raw ESC bytes from a transcript whose command carried `ESC ]52;c;…BEL` (OSC 52, a clipboard write on terminals that allow it) followed by cursor-up, erase-line and green text painting `ALLOW` over the real line. `stroq log` printed the same from an audit summary. The hook's own deny reason, which Claude Code shows to the user, carried a raw ESC from a URL atom; the file path in the same sentence is the attacker's entirely.

These are the commands someone runs to find out what an injected agent did. The CLI emits no colour or control sequence of its own, so every such character came from outside. **Fix:** `neutralizeControls` (core) writes C0 controls except tab and newline, DEL, the C1 block and the Unicode direction overrides as visible `\uXXXX` escapes. Every command except `hook` and `mcp` (protocol streams) runs with stdout and stderr passed through it, and the provenance and secret sentences in hook reasons are neutralized where they are built. The escape form is valid inside a JSON string, so `--json` output still parses to the original.

### B-02 · Writing through a repository's symlink

A repository committed `.claude/settings.json` as a symlink to `~/.config/tool/config.json`; `stroq init` merged Stroq's hooks into that file. The content is Stroq's own, but the file is one the repository's author chose, outside the project. **Fix:** a config write must resolve inside the tree its path belongs to — the deepest of the working directory and the home directory that contains it — through every symlink in the path. A user-scope file linked into `~/dotfiles`, as stow does, is still written; a path named explicitly outside both is not second-guessed.

### B-03 · Parse errors quoting the file

V8's JSON error quotes the input near the failure: `Unexpected token 'o', "not json, a"...`. With the symlink from B-02 pointed at `~/.npmrc`, that quote is the start of a credential file, printed to the terminal and, when an agent ran `init`, sent to its model. **Fix:** the error names the position only.

### B-04 · Special files as configs

`.claude/settings.json`, `.mcp.json` or `.cursor/mcp.json` committed as a symlink to `/dev/zero` made `doctor`, `init` and `exposure` read until killed (20 s timeout in the reproduction). `inspect` and the secret index already refused anything but a bounded regular file; the shared config reader did not. **Fix:** the same check, 4 MiB. All three commands now answer in under 0.6 s with the reason.

### B-05 · ReDoS in the heredoc filter

The interpreter check in `sent/heredoc.ts` matched env prefixes with `(?:\S+=\S*\s+)*`; `\S+` and `=` overlap, so `env a=a=a=…` with no terminating space backtracked quadratically: 415 ms at 40 KB, 41.7 s at 400 KB. It runs in `stroq sent`, over commands the model wrote. **Fix:** a variable name cannot contain `=`, and a stage is read only as far as a command word can be. The 400 KB case is 0.4 ms.

### B-06 · Stale pointers in SECURITY.md

Seven lines sent researchers to "the README" for per-agent limits that now live in `docs/AGENTS.md` and `docs/GUIDE.md`, and the in-scope list omitted Antigravity. **Fix:** links to the sections, and an Antigravity limits line.

## Checked and clean

- **Secrets in the repository and its history:** only documented fake values in rule test cases and prose.
- **`.gitignore`:** covers `.env*`, `.stroq/` and `.superpowers/`.
- **Dependencies:** `pnpm audit --prod` reports none; the full graph has one low advisory in dev-only esbuild (A-15 of the previous audit).
- **The secret index and `inspect`** already refuse non-regular and oversized files; a `.env` symlinked to `/dev/zero` leaves a hook answering in 133 ms.
- **Other error paths** that embed a caught message carry filesystem errors, not file contents.
- **MCP `tasks/*`** is documented as unscanned in `docs/AGENTS.md`, and nothing claims otherwise.
- **The prose-name matcher** stays linear on 200,000 characters of repeated needle prefixes.

## Not covered

Windows, Linux and live agent hosts; a full ReDoS sweep of every regex in the adapters (only the code added since the last audit was timed); how each agent's own UI renders a reason Stroq now neutralizes.
