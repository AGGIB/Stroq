Every incident that mattered ended in an action. Stroq gates the action.

Two hooks, one deterministic policy.

No model in the loop, no network in the hook's hot path.

  1. 1

    Normalization

    Zero-width stripped, homoglyphs folded, base64, hex and URL decoded two levels deep.

  2. 2

    Provenance

    Stroq can name the earlier tool output that contained the package, URL or command fragment seen in a later action.

  3. 3

    Secret egress guard

    Your secrets are indexed as salted hashes. An outbound call carrying one is denied, naming the variable and the file — never the value.

I'm Agybay, a developer from Kazakhstan. I built Stroq because I let agents run in my own repositories and could not find a guard that looked at where an instruction came from rather than what it said.

The honest limit. The content scan is regex over normalized text, not a model, so it is bypassable by construction. That is why enforcement happens at the action. What it still does not catch is written down.
